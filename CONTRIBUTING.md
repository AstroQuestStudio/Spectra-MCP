# Contributing to Spectra

Contributions are welcome, and pull requests are the preferred way to send them. Bug reports, fixes, documentation improvements and new features are all appreciated. For anything substantial, please open an issue first so we can agree on the approach.

## Before you open a pull request

- Make sure `cargo check --workspace --locked` and `cargo test --workspace --locked` pass.
- Keep changes focused, and describe what changed and why.
- Do not include secrets, personal paths or personal data in code, tests or docs.
